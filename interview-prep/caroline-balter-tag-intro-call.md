## If Contentful comes up

You haven't shipped on Contentful. But headless CMS is a category you've been working in — your Kontent.ai demo build last week (Delivery SDK + Management SDK + webhook with ISR revalidation) means you can speak the architecture fluently even without the Contentful-specific reps.

**Honest opener if asked directly:**

> "I haven't shipped on Contentful specifically, but I built a small demo on Kontent.ai last week — same category, same architecture. Delivery SDK on the read side, Management SDK on the write side, webhook with ISR revalidation on the cache side. The pattern's portable; Contentful would mostly be SDK ergonomics and the editor-side workflow."

**Architecture you can speak to:**

- **Two APIs, two purposes.** Content Delivery API (read-only, public CDN, fast) vs Content Management API (read/write, authenticated). Same split as Kontent.ai.
- **Content modeling layer.** Content types with fields, references between types, validation. The schema is editor-facing in the UI; the SDK consumes it.
- **Webhooks + revalidation.** Publish triggers a webhook; the downstream consumer (Next.js with ISR, or whatever framework) revalidates the affected paths or tags. That's exactly the demo you built for Kontent.ai.
- **Spaces and environments.** Multi-environment workflow — dev/staging/prod for content, conceptually like git branches for content data.
- **Preview vs published.** Preview API for drafts and unpublished content; published API for live. Editors work in preview; consumers serve published.
- **GraphQL Content API.** Contentful has it. Reduces over-fetching for nested content; common pairing with Next.js/React Query.

**Why TAG would care:** Contentful + Next.js + Vercel is a default modern agency stack. If TAG runs Contentful engagements, the consumer side is almost certainly Next.js with ISR or on-demand revalidation — exactly the stack pattern you've been working in.

**Smart redirect question if Caroline opens the door:**

> "What's the headless CMS mix on your active book — mostly Contentful, or are you seeing Sanity, Storyblok, Kontent.ai, headless WordPress? Curious where it's concentrating."

**Don't:**

- Claim production Contentful experience.
- Drop Contentful-specific product names you'd only know from shipping (the surrounding ecosystem products around the core CMS) unless asked, and even then, disclaim cleanly.
- Pretend "yes I know it" when asked. Lead with the honest "haven't shipped, but the headless category is the same architecture."
